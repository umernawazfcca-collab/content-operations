# Operating checklist

- Read current authorized scope and canonical records; do not infer recurring permission.
- Confirm service owner; avoid duplicate schedulers and comment jobs.
- Reconcile release ID, exact approved assets, account, timezone and saved instant.
- Read the native publication state; distinguish published from verified.
- For guide campaigns, verify exact post-to-route binding, destination and authorized end-to-end delivery evidence.
- Review comments only within authorized scope; distinguish acknowledgement from final delivery; escalate sensitive questions.
- Record evidence, gaps and partial coverage accurately. Stop when authority, target identity or evidence is unknown.
