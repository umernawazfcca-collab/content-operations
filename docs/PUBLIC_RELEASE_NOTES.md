- Original code and documentation use MIT; applicable third-party notices are retained.
- Generic `content-operations` namespace with no private deployment defaults, credentials, connectors or background services.
- Synthetic fixtures only. Operational trackers, account identifiers, receipts and private assets are excluded.
- The public repository starts with a fresh history; no original private repository history is included.
- Claude Code/web passed bounded synthetic checks. ChatGPT Work passed bounded conversation-reported checks without an exposed raw tool transcript.

- No logo or trademark rights are granted. Original conceptual workflow images are included; embedded fonts and branded source artwork are excluded. Retained font notices do not change MIT's scope.

Build packages from this source using [setup](SETUP.md), and compare their hashes with the host evidence table. A successful import is not proof of execution, live access or permission to act.
