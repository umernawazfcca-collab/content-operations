## Independent review (1 November 2026)
Evidence fields now require non-blank strings across release, acknowledgement and production checks; approval hashes must be SHA-256; approved or scheduled rows need a recorded approval; malformed types report errors instead of crashing; unreadable CLI input exits 2. Seven regression tests added. Walkthrough redesigned with Previous control, locked-stage display, one-pass autoplay and new conceptual PNG/GIF previews. All archive hashes changed; earlier host results no longer apply.

## CLI boundary follow-up (1 November 2026)
Deep JSON decoder recursion and slot arithmetic overflow now produce input errors with exit 2 and no traceback. A valid final slot at the timestamp limit no longer constructs an unnecessary overflowing next slot. Seven regression methods cover nested trackers/logs, range errors, valid controls, deterministic exits, unchanged inputs and the strict object-versus-null contract. The record reference now explains that optional fields may be null inside objects while supplied object sections cannot themselves be null. The current archives were subsequently reviewed and retested on the surfaces listed above.
